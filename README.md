# RE:NODE Launcher for Sons of the Forest

Installs and updates the RE:NODE client mod for Sons of the Forest.

1. Download `RenodeLauncher.exe` from the [latest release](https://github.com/RE-NODE/sons-of-the-forest-launcher/releases/latest).
2. Run it. It finds the game, installs the mod loader and the mod.
3. Open it again any time to update. It updates itself and the mod.

`manifest.json` tells the launcher which versions are current.
